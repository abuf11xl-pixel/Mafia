# 🎮 بوت ديسكورد - لعبة المافيا وألعاب أخرى

## 📋 الألعاب المتوفرة:

### 🎭 لعبة المافيا
لعبة اجتماعية كلاسيكية تتضمن:
- **الأدوار:**
  - 🔴 **المافيا**: تقتل لاعب كل ليل
  - 👮 **المحقق**: يكتشف دور لاعب كل ليل
  - 🏥 **الطبيب**: ينقذ لاعب من الموت
  - 🏘️ **المدنيون**: لاعبون عاديون

- **مراحل اللعبة:**
  - ليل: المافيا تختار الهدف، الطبيب ينقذ
  - نهار: التصويت على إزالة لاعب
  - تصفيات: اللعبة تنتهي عند فوز أحد الجانبين

**الأوامر:**
```
!ماfia [عدد اللاعبين]  - بدء لعبة جديدة
!انضم                 - الانضمام للعبة
!ابدأ                 - بدء اللعبة
```

## 🚀 البدء السريع

### 1️⃣ التثبيت
```bash
pip install -r requirements.txt
```

### 2️⃣ إنشاء بوت ديسكورد
1. اذهب إلى [Discord Developer Portal](https://discord.com/developers/applications)
2. اضغط على "New Application"
3. اذهب إلى قسم "Bot" وأضف بوت جديد
4. انسخ التوكن

### 3️⃣ إضافة التوكن
افتح `main.py` واستبدل:
```python
await bot.start("YOUR_BOT_TOKEN_HERE")  # ضع التوكن هنا
```

### 4️⃣ تشغيل البوت
```bash
python main.py
```
